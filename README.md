# Neko Tools — sitio

Landing page de [Neko Tools](https://nekotools.site), presentando Neko Lista y las próximas herramientas de la marca.

Sitio estático (HTML + CSS + JS vanilla, sin build). `index.html` es el único punto de entrada; `img/` tiene los assets reales (logo, marca y capturas de la app).

## Deploy

Este repo se despliega por Git a Hostinger, apuntando al dominio `nekotools.site`. Cualquier push a `main` se refleja en el sitio.
